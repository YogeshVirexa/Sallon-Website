# Fabeau Luxury Unisex Salon

Official website for Fabeau Luxury Unisex Salon, Coimbatore.

Website: [https://fabeau.in](https://fabeau.in) (Design imported from Scissor Creative Studio)

## Tech Stack

- **Framework**: TanStack Start & TanStack Router
- **Runtime**: React 19 & Vite
- **Styling**: Tailwind CSS & custom design tokens
- **Data Fetching**: TanStack React Query

## Getting Started

### Prerequisites

- Node.js (v20+ recommended)
- npm or pnpm

### Installation

```sh
npm install
```

### Development

```sh
npm run dev
```

### Build

```sh
npm run build
```
